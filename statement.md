# Project Statement

## Problem Statement
Students often have multiple assignments, practice tasks, tests and deadlines. Without a simple tracking system, it can be difficult to know which tasks are pending, completed or overdue.

## Scope
The project provides a command-line system for creating and managing academic tasks, monitoring completion progress and viewing deadlines.

## Target Users
The primary target users are college students who want a simple way to organize academic work.

## High-Level Features
1. Task management
2. Progress tracking
3. Deadline monitoring and reporting
4. Input validation
5. Local JSON-based data storage
