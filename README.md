# Student Study & Assignment Tracker

## Overview
A command-line Python application that helps students manage academic tasks, deadlines, completion status, and progress.

## Main Features
- Add, view, update and delete tasks
- Mark tasks as completed
- Calculate overall and subject-wise progress
- Identify overdue and upcoming deadlines
- Generate a study report
- Validate user input
- Store task data in JSON format

## Technologies
- Python 3
- JSON
- Git / GitHub
- Python unittest

## Project Structure
See the repository folders for the modular implementation.

## How to Run
1. Install Python 3.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

## Testing
Run:

```bash
python -m unittest discover tests
```

## Notes
This project uses only Python standard-library modules, so no external package installation is required.
